## 1. Universal 16-CSR (128-Byte) BAR0 Register Contract

Every policy compiled by `spectralc` targets a fixed 128-byte memory-mapped register file (`0x00..0x78`) across PCIe BAR0, CXL.io/CXL.mem inline bridges, and 512-bit AXI4-Stream network/substation pipelines.

### Binary `.sbundle` Layout (256 Bytes Exact)
- **Bytes `0x00..0x7F` (128 B):** Little-endian image of `CSR 0x00` through `CSR 0x78`.
- **Bytes `0x80..0x87` (8 B):** ASCII magic `"SPECBNDL"`.
- **Bytes `0x88..0x8F` (8 B):** Format version (`0x00010000`) + submode/clamp/degree descriptor word.
- **Bytes `0x90..0xAF` (32 B):** FIPS 180-4 SHA-256 digest computed strictly over `0x00..0x7F`.
- **Bytes `0xB0..0xCF` (32 B):** Domain-separated ML-DSA-87 / CNSA-2.0 envelope commitment.
- **Bytes `0xD0..0xFF` (48 B):** Zero-padded provenance tag (`"SPECTRALC-1.0.0-APACHE2-OUTPUT-OK"`).
