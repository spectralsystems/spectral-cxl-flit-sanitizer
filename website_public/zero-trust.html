Route 03 · Hardware Capability Isolation, LoRA Clamp & Monotonic Latch

Three simple hardware locks: a 64-switch grid, decimal rounding, and a one-way gate.

REDUCTION TO PRACTICE // HOW THE THREE LOCKS WORK

Lock 1 replaces a 250 GB memory table with 64 switches on an 8x8 grid. Lock 2 rounds off tiny trailing decimals on shared AI weights so thieves cannot copy the model. Lock 3 wires permissions through a one-way AND gate (0 x 1 = 0) so even an OS root hack cannot turn a revoked permission back on.

Instead of a 250 GB lookup table in RAM, we use three tiny circuits: (1) an 8x8 grid of 64 switches where each user gets an 8-switch line that crosses any other user's line at most once, (2) a wire mask that rounds off tiny trailing decimals on AI weights so a thief can't clone the model, and (3) a physical AND gate (New = Current x Command) where 0 x 1 = 0, so a revoked permission cannot be turned back on by software.

(2) Serve the Model, Starve the Thief: We round off tiny trailing decimals on AI weights in +0 extra gates so normal AI answers work fine, but a thief copying the model needs 85x to 43,691x more reads before the chip changes the lock. (3) A Permission Bit That Only Moves Down: Wired through a physical AND gate (New = Current x Command), so once a bit is 0, 0 x 1 = 0 forever until the rack is unplugged.

A Permission Bit That Only Moves Down.

Beat 1 · Motivation

In multi-tenant AI clusters, attackers probe shared KV-caches, extract rank-16 LoRA fine-tunes via high-volume logit SVD queries, or abuse root hypervisor privileges to flip revoked access bits back to 1.

Beat 2 · Plain Physical Meaning

Three zero-RAM circuits close all three paths: AG(2,8) finite-plane lines isolate 63 active cohorts in 64 bits; a +0-LUT BFloat16 wire guard + CSR 0x38 cap freezes attacker SVD overlap at 0.000; and a one-way AND2 gate locks revoked SPIDs until cold power-off.

Beat 3 · Scope & Price Paid

Cohort ID 0x00 is permanently reserved as fail-closed null (63 usable slots), online water-filling caps each parallel bucket at n_b < 8 to hold W_8(n) = 0, and restoring a revoked bit in CSR 0x70 requires a physical chassis cold reset (por_cold_rst_n).

No Free Lunch in Algebra — The 7-Revocation Ceiling, AI Rounding Noise & Cold-Reboot Resets

Compressing 250 GB of state into 64 flip-flops and rounding AI weights in hardware imposes three strict mathematical boundaries:

1. Zero Collateral Holds Up to 7 Revocations

Because crossing lines on the 8x8 AG(2,8) grid share 1 switch (and the GF(2^8) Vieta bank holds 8 exact roots), you can revoke 7 full cohort lines or 8 individual IDs instantaneously in hardware. On the 8th line revocation, the software controller must spend ~1.36 ms to push a fresh 128-byte BAR0 bundle.

2. Rounding AI Decimals Adds +0.14% Perplexity

Zeroing the bottom 4 mantissa bits of BFloat16 weights forces a model thief to make 85x to 43,691x more reads (stopped by the 10,000-read epoch cap in CSR 0x38), but it adds a tiny quantization nudge (+0.14% WikiText-2 perplexity).

3. Re-Enabling a Revoked Bit Requires a Cold Power Cycle

Because the capability ratchet is a physical AND gate clocked on the cold power-on rail (por_cold_rst_n), software cannot re-widen a 0 back to a 1—unless an operator signs a dual-key shadow-bank epoch swap or power-cycles the server.
