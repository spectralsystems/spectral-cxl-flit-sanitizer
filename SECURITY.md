# Security & OPSEC Policy

## Zero-Knowledge Repository Scope
This repository hosts only public zero-knowledge verification ledgers and machine-checked Microsoft Lean 4 mathematical proofs (`formal_lean4/SheafCosetIsometry.lean`).

All synthesizable SystemVerilog implementations (`*.sv`), 7nm FinFET Liberty timing models (`*.lib`), and placed-and-routed FPGA checkpoints (`*.dcp`) are maintained in an air-gapped local vault protected under **SBIR Data Rights (DFARS 252.227-7018)** and **USPTO Provisional Patent Application No. 64/183,661** (Filed October 24, 2026; Confirmation No. 3691).

## Vulnerability Disclosure
Report any mathematical proof or cryptographic ledger anomalies directly to `eric@spectralsystems.org`.
